# Security policy

Hearmark handles local browser sessions and downloaded media. Do not put cookies, tokens, private URLs, or personal recordings in an issue or pull request.

For a vulnerability, use GitHub's **Report a vulnerability** link in this repository's Security tab. Include a minimal reproduction, affected version, and impact. If private reporting is unavailable, open a public issue containing only a request for a private contact channel; do not disclose exploit details there.

The beta currently receives fixes on the latest released version. Downloaded models and the media platform are maintained by their respective upstream projects.
