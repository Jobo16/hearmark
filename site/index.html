Browser session when needed

Public access is tried first. If login-only captions are missing or a site challenges the request, yt-dlp can read a local browser session on demand. Hearmark does not store cookies or login state.

↻

Checks for updates

Every run checks the Skill version. Link tasks also check the latest stable yt-dlp and upgrade when needed. Offline checks do not stop a working task.

◇

Honest failures

Private, unavailable, or restricted media can still fail. The agent gets a classified error and a next step, instead of a made-up transcript.

GOOD TO KNOW

Frequently
asked.

Does Hearmark upload my audio to its server?

No. Hearmark downloads media and runs speech recognition on your computer. The website only distributes the Skill package and version manifest.

Which AI agents can use it?

Local agents that support Agent Skills can load it from their user Skill directory. The installer can link the same Skill into another directory when needed. Agents with local command access can run the CLI directly.

When are speech models downloaded?

A model is downloaded from its original provider the first time you choose it. Later runs reuse the local cache. Parakeet and Whisper weights come from Hugging Face; SenseVoice weights come from a sherpa-onnx GitHub release.

Which languages does Hearmark support?

The default model is Parakeet Q8 for English, SenseVoice Small for Chinese, and Whisper Small for unspecified or other languages. Larger Whisper models are optional.

Does every video link work?

No. Private, unavailable, region-restricted, or DRM-protected media may fail. Hearmark reports the access or processing error instead of inventing a transcript.
